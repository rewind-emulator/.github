# Rewind

**One emulator. Every console.**

A cross-platform, all-in-one retro game emulator front-end built on libretro.

</div>

---

## Projects

| Project | Description | Platforms | Status |
|---|---|---|---|
| [Rewind](https://github.com/rewind-emulator/Rewind) | Unified, zero-config front-end that loads [libretro](https://www.libretro.com/) cores | Windows, macOS (mobile planned) | Pre-alpha |

## Why Rewind

- One front-end for many consoles, powered by libretro cores
- Native UI built with .NET MAUI, not Electron
- Zero-config first: add a ROM and play

Free and open source under the GPL v3.

## Community rules

- Our projects never include or link to ROMs, BIOS files, firmware or games. Please dump your own from hardware you own.
- Be kind. Questions about how something works are always welcome.
